# Versão demonstrativa 1.0 — 28/11/2026

Pacote de portfólio sanitizado e testado localmente com dados fictícios, conforme evidências apresentadas pelo autor. A execução manual da cópia importada concluiu os cinco agentes e a gravação de um relatório TXT. O pacote permanece manual e desativado por padrão.

Inclui JSON importável, documentação e testes offline da estrutura e dos nós de código. Não inclui credenciais, dados de execução brutos, backups, relatórios internos nem configurações de autenticação.

Limites: não foi realizada avaliação semântica sistemática das respostas da IA, auditoria integral de segurança ou validação com clientes reais. Os testes do GitHub não fazem chamadas ao modelo. O portfólio demonstra capacidade técnica, não um produto comercial ou SLA.
